NINDY PORTFOLIO
================

Cara menjalankan:
1. Extract ZIP.
2. Buka index.html di browser.

Edit foto:
- Di index.html, cari <div class="photo-placeholder">.
- Ganti dengan <img src="foto.jpg" alt="Nindy">.
- Simpan foto.jpg di folder yang sama.

Edit kontak:
- Ganti hello@nindy.example dengan email kamu.
- Ganti link Instagram di index.html.

File:
- index.html = struktur website
- style.css = desain cream + sky blue
- script.js = animasi, typing effect, dark mode, mobile menu, cursor
